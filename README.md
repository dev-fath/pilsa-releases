# 필사 (Pilsa) 설치 파일

하루 한 줄, 손으로 따라 쓰는 필사 습관 안드로이드 앱의 설치 파일(APK)만 올리는 곳입니다.

- 소개 · 설치 안내: https://dev-fath.github.io/pilsa-releases/
- [Releases](../../releases/latest) 에서 최신 `pilsa-x.y.apk` 를 받아 설치하세요. 릴리즈 본문에 파일의 SHA-256 이 있습니다.
- 안드로이드 7.0 이상. 처음 설치할 때 「출처를 알 수 없는 앱」 설치 허용이 필요합니다.
- 앱은 하루 한 번 새 버전을 확인해 알려 주고, 설정 → 정보에서 이 페이지를 엽니다.

필사 기록은 휴대폰 안에만 저장됩니다. 운영 서버는 없습니다.
