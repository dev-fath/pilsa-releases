‹ 필사

개인정보 · 데이터 안내

필사는 이 휴대폰 안에서만 동작해요. 회원가입이 없고, 운영 서버도 없어서 운영자가 볼 수 있는 정보가 없어요.

휴대폰 안에만 저장하는 것

쓴 날(날짜 · 그날 문구 · 그날 쓴 펜 · 누른 시각), 입문 진도, 연속 기록 · 배지 · 시리즈 진도, 고른 펜 · 잉크 · 종이, 알림 시간과 켜짐 여부, 마지막으로 새 버전을 확인한 시각.

직접 넣은 내 문구, 남기기로 고른 손글씨 사진(앱 저장소에 복사), 켰을 때만 받는 일본어 글꼴 파일.

책 사진에서 문장을 고를 때 글자는 휴대폰 안에서 읽어요. 그 사진은 문장을 고르는 데만 쓰고 기록으로 남기지 않아요.

앱을 지우면 함께 지워져요. 다른 곳에 백업하지 않아요.

알림

정한 시간에 하루 한 번 오늘 문구를 보여 주려고 알림 권한을 물어봐요. 알림은 휴대폰이 스스로 띄우는 예약 알림이고, 밖에서 보내는 푸시가 아니에요. 설정에서 끌 수 있어요.

밖으로 나가는 것

새 버전을 확인하려고 하루 한 번 GitHub(api.github.com)에 이 저장소의 최신 릴리즈를 물어봐요. 이때 GitHub 은 접속 IP 를 알 수 있어요. 기록 · 설정은 보내지 않아요.

새 버전을 받을 때는 GitHub 에서 설치 파일을 내려받아요. 설정 → 정보에서 릴리즈 페이지를 열면 브라우저로 GitHub 페이지를 열어요.

설정에서 「내 문구 일본어」 를 켜면 그 펜의 일본어 글꼴을 GitHub(raw.githubusercontent.com, Google Fonts 저장소)에서 한 번 내려받아요.

책 사진 글자 인식에 쓰는 Google ML Kit 은 진단 · 사용 통계(처리 속도, 이미지 형식 · 크기 같은 설정, 설치마다 다른 식별값)를 Google 에 보내요. Google 이 밝힌 목록에 사진 · 글 내용은 없어요(ML Kit 데이터 안내).

문구 나누기는 내가 고른 앱으로만 보내고, 사진첩에 저장은 이 휴대폰의 사진첩에만 저장해요.

쓰지 않는 것

광고, 따로 넣은 분석 · 크래시 수집 도구, 위치 · 연락처 · 카메라 권한을 쓰지 않아요. 사진은 찍거나 고를 때 휴대폰의 카메라 앱 · 사진 고르기 화면을 빌려 쓰고, 고른 한 장만 앱이 받아요.

글꼴 · 문구

앱에 넣은 글꼴은 나눔손글씨 나는 이겨낸다 · 옥비체 · 할아버지의나눔, 마루 부리(NAVER, 오픈 라이선스), 김정철 손글씨(정림건축문화재단)이고, 라이선스 전문은 앱의 설정 → 라이선스 · 문구 출처에 있어요.

문구는 저작권이 끝난(작가 사후 70년이 지난) 시 · 고전 · 명언에서 골랐고, 출처를 함께 적었어요.

혼자 쓰려고 만든 앱이에요. 문의는 GitHub 이슈로 남겨 주세요.
